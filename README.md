# Personal Resume Website

A personal resume website showcasing my recent professional experience, GitHub projects, and verifiable certificates.

## Live Website

**[View My Resume Website](https://resume-snowy-phi-18.vercel.app/git.html)**

## Features

- **Professional Experience:** Highlights my recent work experience and background.
- **GitHub Portfolio:** Interactive buttons linking to my GitHub projects and repositories.
- **Verified Certificates:** Clickable certificate links that allow visitors to review and verify my credentials.
- **Simple Navigation:** A straightforward interface for recruiters and employers to explore my qualifications and projects.

## Purpose

This project provides a centralized place for employers and recruiters to review my experience, explore my development work, and verify my certificates.
